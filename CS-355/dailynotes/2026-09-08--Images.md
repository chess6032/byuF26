## Interlacing

- Bandwidth-saving technique, introduced back when old cables couldn't transfer data fast enough to work with full images.
- IDEA: Split image in half&mdash;odd rows and even rows. Render one half on one frame, then the other half on the next.

Really useful technique back then, but rarely used anymore. (Although one student said a few modern sports & news companies still use it. So that's interesting.)

## Raster vs. vector graphics

- Vectors: Continuous curves.
  - INFINITE resolution. Wow!
  - Still must be rasterized to be viewed on a raster screen.
    - But at least you can target the resolution to the device.

Classic example: Text. Almost all fonts are stored as vector graphics.  
Another example: Postscript, for printers, which describes to the printer how to move its pen to draw shih.

## Aliasing

Aliasing is the "jaggies" or "stair steps" that occur when rasterizing a curve.

Anti-aliasing is the process of "smoothing out" those jaggies. All it is is blurring the jaggies a little bit.

# Buffers

## Double buffering

- When you draw, you don't write to the screen directly. You write to a **screen buffer**. But modern display hardware/software uses two screen buffers (double buffering): One displayed currently ("offscreen" or **"back" buffer**), and one you're writing to (real screen buffer). When you're finished writing to the back buffer, you'll swap it with the displayed buffer.
    - This way, the user doesn't see the drawing happen in realtime.
    - This swapping is done by display hardware.
- ^ Also sometimes called "video memory".
- ^ Screen buffers are typically stored on the GPU.

(Old computers used to use a single buffer, and you could sometimes see a ghosting effect when stuff moved.)

## Color buffers

Color images are typically one byte each for RGB&mdash;24 bits. But memory words are 32 bits (or some multiple of this). So for speed, you should **word-align your pixels** (meaning for each pixel in a RGB image you'd have an extra empty byte).

BUT, you could also use that fourth byte for an **alpha channel** (opacity).

## Geometric interpretation of vector addition vs. subtraction

- $\mathbf a + \mathbf b$ is the vector that goes from $\mathbf a$'s tail to $\mathbf b$'s head.
- $\mathbf a - \mathbf b$ is the vector that goes from $\mathbf b$'s tail to $\mathbf a$'s head.

```math
\vec a + \vec b = \vec {ba} \newline
\vec a - \vec b = \vec {ab}
```

## Cross products

- Cross product is NOT commutative. $\mathbf u \times \mathbf v \ne \mathbf v \times \mathbf u$.

### Geometric interpretation

For two vectors $\mathbf a$ and $\mathbf b$, $\mathbf a \times \mathbf b$ produces a vector orthogonal to BOTH $\mathbf a$ and $\mathbf b$.
