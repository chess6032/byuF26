Here's some things to remember about Python though:

- Dividing two ints produces a float.
  - This includes ints that divide into each other evenly. e.g., `10 / 2` produces `2.0`, NOT `2`.
- Strings can be indicated with either single or double quotes.
- `True` and `False` are capitalized.
- You can check the type of a variable with `type()`.
- Python features **complex numbers**.
  - Type is called `complex`.
  - Complex literals are indicated like this: <code><i>X</i> + <i>Y</i>j</code>, where `X` is the real part and `Yj` is the imaginary part.
- Multiplying a string repeats it.
  - e.g., `'fa ' + 'la ' * 8` produces `'fa la la la la la la la la'`.
- For a list `l`, `l[:]` returns (a copy of) the whole list.

## Tuples

A tuple is a "heterogenous" collection of objects. Tuple literals are a bunch of comma-separated elements **enclosed by `()`**.

- Tuples are **immutable**. You cannot change the value of their elements.
  - (This is what makes tuples different from lists.)
- Adding two tuples concatenates them.
- Multiplying a tuple repeats it (same as with `str`).
- Tuple indexing is zero-indexed. You index into tuples the same way you index into lists (with `t[idx]`).

Tuples are more efficient. So if speed is important and you don't need to change its values, you should use a tuple. If you need to change the values, use a list.

## Simple assignment

**Simple assignment in Python never copies data**. Simple assignment means `obj1 = obj2`. When you do that, `obj2` points at the same object as `obj1`.

## Lists

- `list.count(item)` returns the number of instances `item` appears in the list.
- `list.remove(item)` removes the first instance of `item`.

### Slicing

- Format: `list[first:last:inc]`
  - `first`: First index (inclusive).
  - `last`: Last index (exclusive). i.e., "first idx to not include."
  - `inc`: "Increment."

Here's some examples:

* `a[n]`: nth element of list a.
* `a[m:n]`: elements of idx m to n-1.
* `a[:]`: all elements.
* `a[m:]`: elements from m and to the last.
* `a[:n]`: eleemnts from first to m-1.
* `a[::q]`: elements from first to last, but only those in increments of q.
* `a[m:n:q]`: elements from m to n-1, but only those in increments of q.
